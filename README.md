# 작성미수

브라우저에서 문단을 자유 배치하고 PNG로 내보내는 정적 웹 편집기.

## 실행

Node.js에서 `node serve.cjs` 실행 후 `http://127.0.0.1:4173` 접속.
로컬 원본은 `dist/` 전체다. 설치할 패키지는 없다. 배포 전 `node scripts/prepare-pages.cjs`를 실행하면 `artifacts/pages/`에 배포 파일을 만든다.

## 사이트와 배포

- 사이트: https://writemisu.github.io/
- 저장소: https://github.com/writemisu/writemisu.github.io
- GitHub Pages의 Source는 GitHub Actions를 사용한다.
- `main`에 변경 사항을 올리면 JavaScript 문법 검사와 자동 테스트를 통과한 뒤 배포 파일을 생성한다. HTML이 불러오는 CSS·JavaScript와 모든 내부 모듈 참조에 같은 콘텐츠 버전을 붙여 이전 캐시와 새 코드가 섞이지 않게 한다. `artifacts/pages/`만 배포하며 원본 `dist/`는 바꾸지 않는다. GitHub Actions에서 수동 실행도 가능하다.
- `serve.cjs`는 로컬 확인용이며 사이트에서 서버를 실행하지 않는다. 입력과 PNG 생성은 브라우저에서 처리한다.
- `artifacts/`는 저장소에서 제외한다. 그 안의 검수 화면·작업 파일은 `pages/` 밖에 두어 배포에도 포함하지 않는다.

## 편집

- 문단마다 독립된 입력칸에서 바로 입력·붙여넣기·수정. 문단 추가 시 새 입력칸 생성. 입력칸 안의 빈 줄과 줄바꿈은 그대로 유지한다.
- 기본 지면 너비 800px. 가운데 480px 본문 한 열에 문단을 위아래로 배치하며 높이는 내용에 맞춘다. 각 문단은 자유롭게 이동하고 너비를 바꿀 수 있다. 화면 맞춤은 가로와 세로를 모두 계산한다.
- 표현: 각 문단 입력칸 위에서 본문·챕터 제목·문자 메시지 알림·문자 대화 표현을 선택한다. 흑백 메뉴에서 현재 항목을 체크로 표시하며 방향키·Enter·Esc로도 선택한다. 챕터 제목은 회색 띠와 사각형 표시, 굵은 제목으로 표현한다. 새 문단은 항상 본문이다. 알림은 제목·시간·발신자를 편집하고, 대화는 좌우를 선택한다. 짧은 말풍선은 내용에 맞춰 줄어들고 긴 내용은 본문 열의 78% 폭에서 줄바꿈된다. 좌우 여백에 자동으로 붙고, 좌우 꼬리와 흰색·옅은 먹청색 배경으로 화자를 구분한다. 직접 옮기거나 너비를 조절하면 자동 가로 배치를 해제하고, 좌우 버튼 또는 문단 자동 배치로 다시 적용한다. 기존 드래그·너비 조절·부분 서식·실행 취소·PNG 저장을 함께 지원한다.
- 기본 글자 크기는 프리젠테이션 20pt, 나머지 글꼴 12pt. 글꼴 변경과 새 문단 생성 시 해당 기본값을 적용한다. 글자 크기 조절은 pt로 표시하고 Canvas 렌더링 시 px로 환산한다. 마지막으로 고른 글꼴은 새 문단과 다음 접속에도 유지한다.
- 이동: 문단 드래그. Shift+클릭으로 다중 선택. 내용 옆 ? 버튼에서 안내를 확인한다. 각 문단 제목 옆에서 개별 삭제한다.
- 묶기/해제: 선택 문단의 상대 위치를 유지하며 함께 이동.
- 수정: 왼쪽 입력칸. 지면 문단 더블클릭은 해당 본문 입력칸으로 이동한다.
- 부분 서식: 왼쪽 입력칸에서 글자를 선택한 뒤 굵게·기울임·밑줄·취소선 적용. Ctrl+B/I/U 지원. 겹친 서식, 실행 취소, PNG 내보내기에 유지한다. 외부 붙여넣기는 일반 텍스트로 받는다.
- 폭: 선택 문단 오른쪽 손잡이. 여러 문단을 선택하면 전체 선택 테두리의 손잡이로 함께 늘리고 줄인다. 디자인의 문단 너비 슬라이더·너비 맞춤 버튼은 선택 문단을 같은 너비로 만든다. 지면 양쪽 여백 가이드와 다른 문단의 오른쪽 끝에도 스냅한다. 가이드는 PNG에 포함되지 않는다.
- 간격: 3개 이상 선택 후 세로 간격 균등 버튼으로 문단 사이를 맞춘다. 간격의 문단 사이 슬라이더는 2개 이상 선택한 문단에 지정 간격을 적용한다. 문단 높이가 달라도 실제 빈 공간을 기준으로 계산한다.
- 글자 설정은 배경색 아래 한 그룹에 모았다. 글자 크기와 행간은 슬라이더로 즉시 반영. 선택 문단이 없으면 전체 본문에 적용한다.
- 정렬은 글 정렬과 레이어 정렬 탭으로 분리. 글 정렬은 왼쪽·가운데·오른쪽·양쪽을 지원하고 레이어 위치를 바꾸지 않는다. 레이어 정렬은 선택 상자·구분선의 실제 위치를 지면 여백 기준으로 옮긴다. 다중 선택은 상대 위치를 유지한다.
- 양쪽 정렬은 자동으로 줄바꿈된 줄만 늘리고 마지막 줄·직접 줄바꿈한 줄은 왼쪽에 둔다.
- 배경은 깊은 밤 원형 그라데이션(`#2D3643` → `#57545F`)과 책 내지 단색(`#F5F5F5`). 원형 중심은 130도 기준으로 고정. 배경 카드 안에서 노이즈 강도 조절 가능.
- 편집기 UI는 밝은 중립색과 먹청색(#40566B) 포인트로 구성한다. 배경·글자·정렬은 카드와 간격으로 구분하고 상단에는 작성미수 글자 로고를 사용한다. 결과물의 배경·글자 색은 별도로 유지한다.
- 데스크톱은 내용 | 디자인(330px) | 지면 순서로 함께 표시한다. 디자인 버튼 또는 접기 버튼으로 디자인만 접고 펼친다. 내용 패널은 넓은 화면에서 440px, 기본 420px이며 오른쪽 경계를 드래그해 최소 280px부터 화면 절반까지 조절한다. 경계에서 방향키로 10px씩, Home/End로 최소/최대를 적용한다. 지면 더블클릭은 디자인을 닫지 않고 해당 내용 입력칸으로 이동한다.
- 좁은 화면(960px 이하)은 한 열로 전환하고 내용·디자인 패널 높이를 제한해 문단이 늘어도 지면을 과하게 밀어내지 않는다. 스크롤바는 감추되 휠·터치 스크롤은 유지한다.
- Ctrl+Z / Ctrl+Shift+Z, 방향키(1px), Shift+방향키(10px), Delete, Esc 지원.

## 내보내기

- 상단 PNG / HTML 모드 전환. 내용과 서식은 공유하지만 HTML은 좌표·레이어 크기·묶음·드래그를 사용하지 않고 문단 순서대로 배치한다. 모드 전환은 PNG 배치를 보존한다. HTML 문서 너비·안쪽 여백·문단 간격은 별도로 저장한다.
- HTML의 각 본문·메시지 문단은 기본적으로 닫힌 `<details><summary>`로 내보낸다. 내용 카드의 접기 제목을 비워 두면 문단 번호를 사용한다. 미리보기에서 제목을 눌러 펼칠 수 있다.
- HTML 복사는 인라인 스타일이 포함된 코드, 서식 복사는 `text/html`과 일반 텍스트를 클립보드에 넣는다. 미리보기와 복사본은 같은 HTML 생성기를 사용한다. 클립보드가 차단되면 코드 보기에서 수동 복사한다.
- HTML은 웹편집기가 허용하는 태그·인라인 스타일에 따라 표시된다. 접기를 유지하려면 `details`와 `summary`를 허용해야 한다. 외부 스타일시트와 스크립트는 포함하지 않아, 대상 페이지에 없는 웹폰트는 지정된 기본 글꼴로 대체된다. 노이즈는 인라인 PNG 배경으로 포함되며 대상 편집기가 data URL 배경을 허용해야 한다.

- 대사 서식: 디자인의 글자 설정 아래에서 전체 문단에 적용하는 ON/OFF를 제공한다. 기본은 OFF이며, 켜면 큰따옴표 `" "`와 `“ ”` 안쪽에 하이라이트(기본 8%)·글자색·굵게·기울임·밑줄·취소선을 적용한다. 하이라이트 농도 0%는 배경 강조를 끈다. 짝이 맞지 않는 따옴표는 건드리지 않는다. 직접 지정한 원본 서식을 바꾸지 않아 OFF로 되돌릴 수 있고, 설정은 실행 취소와 임시저장에 포함된다. 지면과 PNG가 같은 서식을 사용한다.
- 전각 공백(U+3000)은 글꼴의 원래 너비를 유지하되 글리프를 그리지 않는다. 코펍에서 공백에 나타나던 점을 방지하며 실제 가운데점(U+00B7)은 그대로 표시한다.

- PNG: 동일한 Canvas 렌더러와 고정 시드 배경 사용. 기본 크기 / 고화질 2배 중 선택하며 마지막 선택을 기억한다. 긴 지면은 최대 변 16,000px 및 총 1,600만 픽셀에 맞춰 해상도 조정.
- 글꼴 메뉴는 본문(코펍돋움·코펍바탕·프리텐다드·Noto Serif KR)과 헤더(프리젠테이션)로 구분한다. 프리젠테이션의 Regular/Bold 웹폰트는 공식 저장소에서 받아 `dist/fonts/`에 포함했으며 SIL OFL 1.1 라이선스는 `dist/FREESENTATION-LICENSE.txt`에 동봉했다. 기본 본문은 코펍바탕이며 마지막에 고른 글꼴을 우선한다. 코펍은 기존 CDN 웹폰트로 제공한다. 공식 안내의 일반 무료 사용 조건과 웹서비스 임베딩 별도 승인 항목은 [KoPub 공식 안내](https://www.kopus.org/biz-electronic-font2/)를 참고한다. 본문 글꼴은 웹폰트로 지원한다. Google Fonts와 jsDelivr에서 불러오며 PNG는 사용한 글꼴 로딩 완료 후 저장.
- 자동 임시저장: 입력·서식·문단 배치·너비·묶음·배경을 최대 0.5초 간격으로 이 브라우저에 저장한다. 탭을 숨기거나 닫거나 새로고침할 때도 남은 변경을 즉시 저장한다. 같은 탭을 새로고침하면 해당 탭의 작업을, 새 탭으로 접속하면 가장 최근에 저장한 작업을 복원한다. 새 탭을 열거나 변경 없이 닫는 것만으로 다른 작업을 덮어쓰지 않는다. 실행 취소/다시 실행 기록 자체는 접속 간 보관하지 않는다.
- 임시저장은 갱신된 문서 데이터를 바로 직렬화한다. 전체 입력칸 재탐색·전체 깊은 복제를 생략하고 한글 조합 중인 입력칸만 별도로 읽는다. 이미 그린 배치는 다시 계산하지 않으며, 그리기 전에 탭을 닫을 때만 마지막 배치를 계산한다.
- 지면 아래에 임시저장 상태를 표시한다. 저장 공간 부족·브라우저 차단으로 저장에 실패하면 실패 상태와 안내를 표시하고, 저장되지 않은 채 나갈 때 브라우저 경고를 띄운다. 임시저장은 서버 동기화나 영구 백업이 아니다. 다른 브라우저·기기로 이동하거나 사이트 데이터를 지우면 이어서 복원할 수 없다. 업데이트 전에 이미 열려 있던 구버전 탭의 내용은 소급 저장되지 않는다.

## 검증

`node --test tests/*.test.mjs`

자동 검증: 문단 분리, 한글·이모지 줄바꿈, 경계 문장부호, 입력 서식 이스케이프, 묶음 이동·너비 경계, 균등 간격, 오른쪽 스냅, 본문·메시지 치수와 서식 보존, 원형·단색 배경, 양쪽 정렬과 구분선 정렬, 임시저장 왕복·손상 데이터 거부·저장 실패·탭별 복원.
브라우저 검증: 붙여넣기, 더블클릭 편집, 개별/묶음 드래그, 폭 조절, 실행 취소, PNG 실제 파일, 50문단(13,939px 지면), 390px 화면, 입력 직후 새로고침·닫고 재접속·여러 탭의 개별 작업·서식과 배경·빈 문서 복원, 100문단·52,492자 입력 후 마지막 수정까지 재접속 복원.

브라우저가 지원하면 WebMCP `read_layout`, `insert_paragraphs`을 노출한다. 유효 입력과 잘못된 입력 후 상태 보존을 확인했다.
